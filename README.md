# FoxESS Dashboard Documentation

## Overview

The FoxESS Dashboard is a Streamlit-based web application that provides a user-friendly interface for monitoring and managing the FoxESS solar inverter system. It complements the main Python script by offering visual insights into system performance and operational status.

## Architecture

### Main Components

- **app.py**: Main application file containing authentication, navigation, and page routing
- **config.yaml**: Configuration file for user authentication and session management
- **home.py**: Placeholder for home page components (to be implemented)
- **scripts/**: Utility modules and scripts for data processing
  - **utils.py**: Common utility functions for API authentication and timestamp generation
  - **history.py**: Functions for fetching and processing FoxESS historical data

### Dependencies

- **Streamlit**: Core web framework for building the dashboard
- **streamlit-option-menu**: Enhanced sidebar navigation with icons
- **streamlit-authenticator**: Secure authentication system with hashed passwords
- **PyYAML**: YAML file parsing for configuration management

## Authentication System

The dashboard uses `streamlit-authenticator` for secure user management:

- Passwords are stored as bcrypt hashes
- Session management via secure cookies
- Configurable login attempt limits and expiry

### Configuration

Authentication settings are stored in `config.yaml`:

```yaml
cookie:
  expiry_days: 30
  key: <secure_random_key>
  name: foxess_dashboard_cookie
credentials:
  usernames:
    <username>:
      email: <email>
      first_name: <first_name>
      last_name: <last_name>
      password: <bcrypt_hash>
```

## User Experience Flow

### Login Process
- **Initial Visit**: Users see only the login form, no sidebar or main content
- **Authentication**: Upon successful login, users are redirected to the home dashboard
- **Session Management**: Authentication state is maintained via secure cookies

### Navigation
- **Sidebar**: Appears only after successful authentication
- **Menu Options**: Home and Settings pages accessible via sidebar
- **Logout**: Clicking logout immediately returns to login screen

### Security
- Failed login attempts are handled gracefully
- Session expiry managed through cookie configuration
- Secure logout clears authentication state

## Utility Functions

### `scripts/utils.py`

Contains core utility functions used throughout the dashboard:

- `get_signature(path, token)`: Generates API authentication signatures
- `get_headers(path, token)`: Creates authenticated HTTP request headers
- `get_sydney_timestamps(hours)`: Generates Sydney timezone timestamps

### `scripts/history.py`

Provides functions for working with FoxESS historical data:

- `get_device_history_data(api_key, inverter_sn, variables, start_time, end_time, period)`: Fetch historical data from FoxESS API
  - `period` options: "custom" (use start_time/end_time), "day" (yesterday's data), "3months" (last 90 days)
- `save_history_data(data, filename, period)`: Save history data to JSON file with auto-generated filename
- `load_history_from_file(filename)`: Load history data from JSON file

## Data Integration

The dashboard reads data from files generated by the main script:

- `foxess_history_YYYYMMDD.json`: Daily export data points
- `foxess_log.txt`: Operation logs for status display
- `error.txt`: Error logs for troubleshooting

## Security Considerations

- All passwords must be hashed before storage
- Use strong, unique cookie keys
- Regularly rotate authentication secrets
- Implement proper access controls for production use

## Development Notes

### Running the Dashboard

```bash
cd dashboard
streamlit run app.py
```

### Adding New Pages

1. Update the `option_menu` in `app.py` with new page names
2. Add corresponding conditional rendering blocks
3. Create separate Python files for complex page logic

### Data Visualization

Use Streamlit's built-in charting capabilities:
- `st.line_chart()` for time series data
- `st.metric()` for key performance indicators
- `st.dataframe()` for tabular data display

### State Management

Leverage Streamlit's session state for:
- User authentication status
- Form data persistence
- Page navigation state
